# Plataforma Macaúba

Dossiê interativo de **demonstração** sobre bioeconomia da palmeira macaúba (*Acrocomia aculeata*): simulador de hectares, balanço de massa e eixos de SAF, HVO, alimento e carbono.

Não é um estudo oficial nem uma plataforma de investimento. Os números do simulador são ilustrativos.

[Live](https://macauba-plataforma.vercel.app)

---

## Demonstração

- **App:** [https://macauba-plataforma.vercel.app](https://macauba-plataforma.vercel.app)

**Caminho do avaliador:** abrir a página → rolar o dossiê → mover o simulador de hectares → ler o recálculo de produção e faturamento.

Não há login. Tudo roda no navegador.

---

## O que o avaliador vê

| Interativo | Editorial |
| :--- | :--- |
| Simulador de área plantada (10–100 M ha) | Eixos de defesa, alimento e petroquímica verde |
| Recálculo de SAF, HVO, farelo e biocarvão | Matriz de coprodutos por tonelada |
| Fundo em Canvas | Créditos de carbono (texto de cenário) |
